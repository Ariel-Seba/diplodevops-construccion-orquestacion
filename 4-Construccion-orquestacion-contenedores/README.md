# DiploDevOps

¡Bienvenido a la materia "Construcción y orquestación de contenedores"!

En este repositorio podrá consultar el material para la parte práctica de la materia.
Encontrará una carpeta por cada clase (8 en total). Cada clase contiene un README con un resumen de los temas a ver, comandos útiles, ayudas, etc.

## Colaboración

Se permite colaborar con el material y proponer cambios. Para ello, se pide encariñadamente que abra un MR y avise alguno de los maintainers.
